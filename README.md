# 🐍📚 Python Learning Journey

Este repositório reúne meus **estudos e práticas em Python**, desenvolvidos de forma autodidata para aprofundar os conhecimentos adquiridos no curso e evoluir na programação.

A proposta não é apenas aprender a sintaxe da linguagem, mas **compreender os fundamentos da programação**, desenvolver raciocínio lógico e aplicar os conceitos na prática por meio de exercícios, experimentos e pequenos projetos.

---

## 🎯 Objetivo

* Desenvolver lógica de programação utilizando Python
* Compreender estruturas fundamentais da linguagem
* Praticar resolução de problemas através de exercícios
* Construir uma base sólida para áreas mais avançadas da tecnologia
* Evoluir gradualmente para projetos mais complexos

---

## 📂 O que você vai encontrar aqui

* Exercícios de lógica de programação
* Prática com tipos de dados e variáveis
* Estruturas condicionais (`if`, `elif`, `else`)
* Estruturas de repetição (`for`, `while`)
* Funções e modularização de código
* Experimentos e pequenos desafios de programação
